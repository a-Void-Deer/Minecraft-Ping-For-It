# Ping For It Changelog

Unreleased changes accumulated since `76da69e40d4d2b55688ee0dee46d01b07a9ad3d7`.

## UI Update

- Updated config settings screen UI, including the layout of the client and server scopes, category navigation, and option presentation. The settings screen now features native vanilla-style scope tabs, improved category layouts, and enhanced option widgets for better user experience.

## Config Updates

- Changed some upper & lower bounds and defaults of some config options.

## Bug fixes

- target missing string is now correctly localized。
- The HUD now correctly displays the alpha of the ping marker, and the alpha is now correctly applied to the marker's color.
- "client ping duration" option now shows its config name even when it is set to "Follow server" sentinel.

## Documentation

- Refined documentations of the respondary for easier understanding and maintenance. AI helped about docs, and have been reviewed.
