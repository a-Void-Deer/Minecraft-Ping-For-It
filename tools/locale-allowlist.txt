# --- statically used but not literal in Java ------------------------------
# Minecraft derives the key-category title from the KeyMapping.Category
# Identifier registered by InputUtils (pingforit:name); no literal exists in
# our source, but the client reads key.category.pingforit.name at runtime.
used-ok key.category.pingforit.name # Minecraft KeyMapping.Category identifier (pingforit:name)
# Sound subtitles are consumed by the sound engine from the sound event id;
# our Java source never spells the subtitle key.
used-ok subtitles.pingforit.ping # sound engine subtitle for pingforit:ping
