# Contributing to Ping Wheel

Thank you for your interest in contributing to **Ping Wheel**!  
To ensure a smooth process, please follow these guidelines.

---

## 📌 Branches and Versions

### **Default Branch (1.18.2)**
- This is the **primary development branch** and the only one where new features are built.
- All pull requests (PRs) **must** target this branch unless explicitly stated otherwise.

### **Version Branches**
- **PRs for migrations to the latest version**:
  - If a version branch for the latest Minecraft version **already exists** but the mod hasn't been published yet, PRs for **migration purposes only** are **allowed but not encouraged**.
  - These PRs should focus **solely** on porting the mod to a newer Minecraft version.
  - **No new features** will be accepted in version branches.
- **No PRs for other branches**:
  - If a version branch **does not exist**, PRs for that version will **not** be accepted.

---

## 🚀 Pull Requests
- PRs, if merged, are **usually squashed** into a single commit.
- If you still want to adhere to the repository's commit pattern:
    - Use [gitmoji.dev](https://gitmoji.dev/) for commit prefixes.
    - Complete the sentence *"if applied, this commit will..."* in your commit message.
    - Review the git history to understand the expected format.

---

Thanks for contributing! ✨
