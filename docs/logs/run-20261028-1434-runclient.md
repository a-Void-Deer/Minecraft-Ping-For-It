## 关键发现（超出 6 项，但本轮最重要）

**两个 mixin 都成功注入了**（debug.log 的 `Mixing ... into ...` 是 mixin 应用时的正面日志）：
```
debug.log:985  Mixing ExampleClientMixin from modid.client.mixins.json into net.minecraft.client.Minecraft
debug.log:1071 Mixing ExampleMixin from modid.mixins.json into net.minecraft.server.MinecraftServer
debug.log:992  modid.client.mixins.json:ExampleClientMixin from mod modid->@Inject::init(...) doesn't use it's CallbackInfo
```
→ 说明 mixin 配置的 `package`、类是否进数组、refmap/remap 全部正常（AGENTS.md §6-4 的分诊 ①②③ 都过关）。

**但注意边界（别过度解读）**：
- `Mixing` 证明的是**字节码注入成功**，不等于注入的回调被**执行**。
- `run/saves` 为空（0 项）、日志无 `IntegratedServer`/`loadLevel` → **没进世界**，
  所以 `ExampleMixin` 注入的 `loadLevel` 回调**一次都没跑过**。
- `ExampleClientMixin` 注入 `Minecraft#run`，主循环跑了 26 秒，其回调**确实执行过**
  （阶段是主菜单，未进入世界）。

## 对 AGENTS.md 的建议（交 1号 定夺）

- §6-4（P2 mixin 目标未运行验证）：建议改成**两层表述**，别合成一句：
  「注入已织入（`debug.log:1071`）／`loadLevel` 回调未执行（未进世界）」。
  现有写法「`MinecraftServer` 那条注入仍属未验证」容易被读成「可能没织进去」，
  会把人往 mixin 配置方向带偏；实际上配置、package、refmap 都有正面证据。
- §6-2（编译已通过/运行期未验证）：**运行期已验证到主菜单**，可再降一级；
  但仍无功能验证（无自有代码、无进世界、无存档）。

## 口径声明（按 Lead 要求写死）

> 「验证」= **进过世界、`loadLevel()` 被真实调用**。仅启动到主菜单**不算**验证。
> 本轮的结论只说：**能启动、能加载 mod、能正常退出、两个 mixin 都织入了**。
> **不**说：mod 功能可用、`loadLevel` 的注入逻辑正确。
