# 47 · M8a 设置界面 · 实机验收清单

> 用途：M8a-1b 完整分页界面的**人工验收**（本地只能证明编译，视觉效果必须实机）。
> 结果请按「步骤编号 → 通过/不通过 → 现象」回填；不通过时附 `run/logs/latest.log`。

## 0. 准备

1. 终端：`./gradlew -g D:/Gradle runClient`（工作树当前 `eaac541`，compile-check main 266 / client 120，0 error）
2. 建**两个**单人存档：
   - **存档 A**：创建时 **允许作弊 = 开**（服务端设置区应可编辑）
   - **存档 B**：创建时 **允许作弊 = 关**（服务端设置区应锁定）
3. 记录测试前 `run/config/pingforit.json` 内容（用于比对持久化）

## 1. 范围 tab（自写 `ScopeTabButton`，最高风险项）

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | `/pingforit config` 打开界面 | 顶部出现两个 tab：客户端设置 / 服务端设置（本地化文案） |
| 1.2 | 观察 tab 外观 | **原版 tab 贴图**（上方圆角、下方开口），**不应**出现深色矩形底块（那是菜单 tab 的 `MENU_BACKGROUND`），**不应**有下划线 |
| 1.3 | 观察选中态 | 当前 tab 用 `tab_selected` 贴图，且**文字比另一个 tab 高约 3px** |
| 1.4 | 鼠标悬停 | tab 变高亮贴图 + 指针变手型 |
| 1.5 | 点击「服务端设置」 | 列表内容切换为服务端分类，tab 选中态跟随 |

> 不通过时截一张图即可判定（贴图错 / 文字偏 / 有黑底）。
